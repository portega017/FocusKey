# FocusKey

FocusKey is an iOS app project that combines focus sessions with NFC interactions.

## Requirements

- macOS
- Xcode (latest stable recommended)
- iOS device or simulator compatible with the selected scheme

## Open the project

Open the project in Xcode:

- `FocusKey.xcodeproj`

## Run

1. Select the `FocusKey` scheme.
2. Choose a simulator or device.
3. Press Run (`Cmd + R`).

## Repository hygiene

This repository includes a `.gitignore` configured for Xcode/macOS files to avoid committing local machine artifacts.
